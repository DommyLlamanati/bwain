# Recently Tended

A list of your most recently updated notes on the home page.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/recently-tended/` in your garden repo.

## Settings

- **Heading**
- **Number of notes**
