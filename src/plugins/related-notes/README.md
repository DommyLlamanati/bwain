# Related Notes

Suggests related notes under each note, based on the link graph neighborhood.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/related-notes/` in your garden repo.

## Settings

- **Heading**
- **Number of suggestions**
